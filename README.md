# Smart Disaster Relief Coordination Platform

## Overview
A secure, scalable, cloud-based web application to coordinate disaster relief efforts using DevSecOps practices.

## Features
- Role-based access: Admin, Volunteer, Citizen
- CRUD operations: Requests, Resources, Volunteers
- Media uploads (images/videos stored in AWS S3)
- Admin dashboard with statistics and monitoring

## Tech Stack
- Backend: Python Flask
- Frontend: HTML/CSS/JS
- Database: AWS RDS (MySQL)
- Deployment: AWS EC2, Docker, Jenkins CI/CD
- Monitoring: AWS CloudWatch

## Repository Structure
- `src/` → Application source code
- `infra/` → Infrastructure as Code
- `scripts/` → Deployment scripts
- `docs/` → Documentation & screenshots
